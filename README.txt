Video Hover Preview
===================

Автор: Требников Сергей

Превью видео и изображений при наведении курсора
на файл в Проводнике Windows.

Запуск
------
1. Распакуйте архив в любую папку.
2. Запустите VideoHoverPreview.exe
3. Появится иконка в трее (около часов).
4. Наведите курсор на видео или картинку в Проводнике.

Меню трея: Включить/Выключить, Настройки, «О программе».

Состав
------
VideoHoverPreview.exe  - лаунчер
launch.py              - точка входа
video_hover_preview\   - код программы
runtime\ffmpeg\bin\    - ffplay / ffmpeg
runtime\python\tools\  - портативный Python с библиотеками

Лицензии сторонних компонентов
------------------------------
ffmpeg / ffplay - распространяются по своим лицензиям
(обычно GPL/LGPL в зависимости от сборки).
Python и библиотеки - по своим лицензиям в runtime.
